# 🚀 DataMiner Ultra | Enterprise Intelligence

**DataMiner Ultra** هو تطبيق سطح مكتب مستقل ومتطور مصمم بلغة بايثون لاستخراج وهيكلة البيانات من مواقع الويب بسرعة فائقة، مع تصديرها إلى تقارير وجداول منظمة بضغطة زر واحدة.

---

## ✨ أبرز المميزات والخصائص

* **محركان سحب مزدوجان:**
  * ⚡ **محرك Requests:** لاستخراج البيانات بسرعة فائقة من الصفحات الثابتة والعادية.
  * 🌐 **محرك Selenium:** للتعامل التلقائي مع المواقع الديناميكية المعقدة التي تعتمد على جافاسكريبت.
* **فلترة ذكية للمحتوى:** سحب جميع عناصر الصفحة، أو العناوين المخصصة (`H1`–`H4`)، أو الروابط، أو كتل النصوص المهيكلة.
* **جدول نتائج تفاعلي حي:** معاينة فورية للبيانات المستخرجة مع خاصية البحث الحي عبر آلاف السجلات.
* **تصدير متعدد الصيغ:** تصدير فوري بنقرة واحدة إلى ملفات **Excel (`.xlsx`)**، **CSV**، و **JSON**.
* **دعم ثنائي اللغة:** إمكانية التبديل السلس بين **اللغة العربية** و**اللغة الإنجليزية**.
* **ملف تنفيذي مستقل (`.exe`):** يعمل مباشرة على نظام ويندوز دون الحاجة لتثبيت أي برامج مساعدة.

---

## 🛠️ التقنيات المستخدمة

* **البرمجة الأساسية:** Python 3
* **واجهة المستخدم:** Tkinter (تصميم عهدي وعصري بمظهر داكن)
* **السحب والمعالجة:** Requests, BeautifulSoup4, Selenium
* **هيكلة وتصدير البيانات:** Pandas / OpenPyXL / JSON
* **التجميع والتحويل:** PyInstaller
